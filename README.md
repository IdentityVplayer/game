# 🎮 7X7X-H5小游戏合集

一个包含100个精选HTML5小游戏的综合游戏平台，为用户提供丰富多样的游戏体验。

## 🌟 项目特色

- **100个精选游戏**：涵盖动作、益智、策略、射击、体育、音乐等多个类型
- **响应式设计**：完美支持桌面端和移动端设备
- **多主题模式**：正常模式、深色模式、护眼模式
- **游戏存档系统**：支持本地存档的导入导出功能
- **智能搜索过滤**：支持按名称搜索和分类筛选
- **模态框游戏体验**：游戏在弹窗中运行，无需跳转页面

## 🛠 技术特点

- **纯前端实现**：基于HTML5、CSS3、JavaScript
- **无需服务器**：可直接在GitHub Pages等静态托管平台部署
- **模块化设计**：每个游戏独立，易于维护和扩展
- **本地存储**：使用localStorage实现数据持久化
- **跨浏览器兼容**：支持现代主流浏览器

## 🎨 界面功能

### 主题切换
- **正常模式**：经典的蓝紫渐变配色
- **深色模式**：护眼的深色主题
- **护眼模式**：淡绿色调减少视觉疲劳

### 存档管理
- **下载存档**：将游戏进度保存到本地文件
- **导入存档**：从本地文件恢复游戏进度
- **重置数据**：清除所有本地存储数据

### 搜索过滤
- **关键词搜索**：支持游戏名称模糊搜索
- **分类筛选**：按游戏类型快速过滤
- **分页加载**：每页显示24个游戏，支持加载更多

## 🚀 部署说明

本项目已经过优化，可以直接部署到GitHub Pages：

1. **仓库要求**：确保包含`.nojekyll`文件以禁用Jekyll处理
2. **文件结构**：
   ```
   ├── index.html          # 主页面
   ├── games/             # 游戏文件目录
   │   ├── snake.html     # 贪吃蛇游戏
   │   ├── tetris.html    # 俄罗斯方块
   │   └── ...            # 其他游戏文件
   ├── .nojekyll          # 禁用Jekyll
   └── README.md          # 项目说明
   ```

3. **访问地址**：`https://username.github.io/repository-name/`
