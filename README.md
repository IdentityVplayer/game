## 🛠️ 技术栈

- **前端**: HTML5 + CSS3 + JavaScript

- **样式框架**: 自定义CSS Grid布局
- **版本控制**: Git
- **部署平台**: GitHub Pages

## 🔧 自定义和扩展

### 添加新游戏
1. 在 `games/` 目录下创建新的HTML文件
2. 确保游戏是自包含的（CSS和JS内联）
3. 更新主页面的游戏总数

### 修改样式
- 编辑 `index.html` 中的CSS样式
- 支持自定义主题色彩
- 响应式设计易于定制

### 游戏分类
- 通过修改JavaScript中的 `gameTypes` 数组添加新类型
- 更新过滤按钮和描述映射
